# Android Development Internship Projects

This repository contains all the practical tasks and applications developed during my Android Development Internship. Each project is organized in its respective directory with source code and assets.


### Projects Overview

### 1. FirstApplication
* Basic introductory app covering Android Studio project structure, Activity lifecycle, and simple UI layouts.

### 2. My1stApp (AI Chatbot)
* An AI-powered interactive chatbot application built with Kotlin.
* Integrated Groq API using Volley HTTP networking to handle user prompts and display model responses.
* Safe handling of credentials using `local.properties` and `BuildConfig`.

### 3. Calculator
* A modern dark-themed calculator app designed with ConstraintLayout and Material CardViews.
* Features clean expression parsing, BODMAS calculation logic, real-time input preview, and basic arithmetic operations.

### 4. RecylerBing (Friend Request UI)
* Social media-style friend request management interface built using `RecyclerView` and custom Adapters.
* Custom dark theme styling with interactive Confirm and Delete action buttons.

### 5. CollegeWebview
* Web integration app utilizing Android `WebView` to render college portals with JavaScript enablement and in-app navigation handling.

##  Tech Stack & Tools

* **Language:** Kotlin
* **IDE:** Android Studio
* **Architecture / UI:** XML, ConstraintLayout, CardView, Material Components
* **Networking / Libraries:** Volley, JSON parsing
* **Version Control:** Git, GitHub
